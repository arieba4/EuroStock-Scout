# EuroStock Scout v2.1

New in v2.1:
- Side-by-side European and Canadian market buttons.
- Regional beta benchmark with automatic fallback if the ETF benchmark is unavailable.
- Better API error messages and a connection test.
- Dividend status and trailing-12-month yield when Twelve Data dividend access is available.
- Scout Grade A+ to F.
- Morningstar research button. Morningstar stars are proprietary and are not fabricated or scraped by the app; automatic display would require licensed Morningstar data.

## Update GitHub Pages
Replace the six files in the root of the existing EuroStock-Scout repository with these six files and commit the changes. GitHub Pages will redeploy automatically.

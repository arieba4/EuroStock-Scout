How v3.4 ranking works
v3.4 first removes poor data and illiquid securities, then applies trend and market-context filters before complete scoring. Scout Score measures technical quality; Opportunity Score measures whether the entry is attractive now. The Top 5 remains action-first: BUY ZONE → WAIT → AVOID. Relative strength is always measured against the stock's own regional benchmark. Earnings within seven days block a new BUY ZONE by default.
How v3.4 gets market data
A GitHub Actions job runs on weekdays and can also be started manually. It uses the open-source yfinance Python library on GitHub's server to fetch historical prices and dividends, calculates beta/volatility diagnostics, then commits only the resulting JSON data to this repository. Your phone and laptop no longer make dozens of market-data API calls. The data is intended for personal/research use and is end-of-day/delayed rather than a brokerage execution feed.
Decision-support prototype only, not individualized investment advice. “Top 5” means strongest model signals, not guaranteed gains. A 3–4% target is an objective, not a guaranteed return. Verify material news, earnings, taxes and actual execution prices before trading.
